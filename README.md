# 저당과자 저당퐁

팝한 톤의 미니멀한 저당과자 브랜드 홈페이지입니다.

## 로컬에서 보기

빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버가 필요하다면 다음 명령을 사용하세요.

```bash
python3 -m http.server 4173
```

그다음 `http://localhost:4173`으로 접속합니다.

## 파일 구성

- `index.html` — 페이지 콘텐츠와 구조
- `styles.css` — 반응형 스타일과 애니메이션
- `script.js` — 모바일 메뉴, 스크롤 등장 효과, 맨 위로 이동

제품명, 영양 정보, 이메일, SNS 링크와 블로그 글은 자연스러운 임시 내용으로 작성되어 있습니다.
